### Important note on GitHub limits

GitHub recommends keeping individual files under **100 MB**. Files larger than this cannot be reliably pushed to a normal git repository and should instead be attached to a **GitHub Release** (or hosted externally / via Git LFS).

The binary is therefore **not** included in the repository tree.

### How to add the binary yourself

2. Click **Releases** → **Create a new release**
3. Tag: `v0.6.0`
4. Title: `SPITFIRE 0.6.0 Windows x64`
5. Attach `SPITFIRE-0.6.0-Windows-x64.exe` as a release asset
6. Publish the release
